
# CodeOrbit To-Do List Web App

## Project Description
A responsive To-Do List Web Application developed using HTML, CSS, and JavaScript as part of the CodeOrbit Tech Full Stack Development Internship.

The application helps users organize and manage their daily tasks.

## Features
- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Save tasks using browser localStorage
- View total, completed, and pending task counts
- Clear all completed tasks
- Responsive user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser localStorage

## Project Structure
CodeOrbit_ToDo_List/
- index.html
- style.css
- script.js
- README.md

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
4. Start adding and managing your tasks.
